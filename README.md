# Water Quality Prediction

This project predicts water quality using machine learning.

## Features

- Turbidity (cm)
- DO (mg/L)
- pH
- Temperature
- BOD (mg/L)

## Target

- Water Quality

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Joblib
- Render

## Model Deployment

The trained machine learning model is deployed as a web application using Flask and Render.
